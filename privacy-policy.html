1. 처리하는 정보와 목적

한 칸 가계부는 사용자가 직접 입력한 거래 금액·일자·사용처·지역·메모·분류·결제수단·예산과, 사용자가 선택적으로 불러온 금융 문자·알림·사진 인식 결과를 기기 내에서 가계부 작성에 이용합니다.

  • 금융 문자 자동 수집: 별도 동의와 SMS 권한을 받은 뒤 신규 SMS의 본문·발신번호·수신 시각을 확인하고 금융 거래로 판정한 후보를 저장합니다.
  • 최근 금융 문자 가져오기: 사용자가 요청할 때 최근 한 달의 SMS 수신함을 조회합니다. 금융 판정을 위해 비금융 문자를 메모리에서 확인할 수 있으나 금융 거래로 판정하지 않은 문자는 앱 데이터베이스에 저장하지 않습니다.
  • 금융 알림: 별도 동의와 Android 알림 접근 허용 후 알림 제목·본문·발신 앱 패키지명·수신 시각을 확인합니다. 대화형 알림은 메시지별로 판정하고 금융 거래로 판정한 메시지만 저장합니다. 자동 판정에는 오류가 있을 수 있습니다.
  • 대략적인 위치: 사용자가 현재 위치를 요청할 때 거래 지역명을 채우는 데 이용합니다. 지속적인 백그라운드 위치 추적은 하지 않습니다.
  • 사진 인식: 사용자가 선택한 사진에 기기 내 문자 인식을 실행하고 사용자가 확인한 거래·상품 정보를 저장합니다.

2. 외부 서비스 및 제3자 처리

개발자 서버로 금융자료를 업로드하는 기능, 회원가입, 광고 SDK 및 클라우드 자동 동기화는 없습니다. 다만 운영체제와 포함된 SDK의 통신까지 전혀 없다는 의미는 아닙니다.

사진 인식에는 Google ML Kit가 포함됩니다. 입력 사진과 인식 결과는 기기에서 처리되지만 SDK는 기기·앱 정보, 설치별 식별자, 성능·오류·API 설정 등 진단정보를 Google에 전송할 수 있습니다. ML Kit 데이터 공개 안내와 ML Kit 약관을 확인해 주세요.

지역명 변환에는 기기의 Android 위치·주소 제공자가 이용될 수 있습니다. 백업 파일 제공자로 클라우드 저장 위치를 선택하면 해당 제공자의 개인정보처리방침이 적용됩니다.

4. 삭제와 권리

개별 거래와 가져온 알림은 앱에서 삭제하거나 무시할 수 있습니다. Android 설정에서 권한을 해제하면 이후 접근은 중단되지만 이미 저장된 자료는 자동 삭제되지 않습니다. 전체 로컬 자료와 동의 기록은 앱 저장공간 삭제 또는 앱 제거로 삭제할 수 있으며 복구할 수 없습니다. 별도 계정이 없어 회원 탈퇴 절차는 없습니다.

SMS·알림·위치 접근을 허용하지 않아도 거래를 수동으로 입력할 수 있습니다.
